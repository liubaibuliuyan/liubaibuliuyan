01

MC_Bus — 确定性实时调度框架

stm32h743 / c11 / 自研
核心运行中

对标 RTOS，但走时间触发静态调度表的路线：sched_bus 管节拍与相位，data_bus 管数据编解码，func_bus 管功能注册。

展开复盘
问题
动态优先级 + 抢占让最坏响应时间难以证明，而控制环真正需要的恰恰是一个可证的上界。
约束
Cortex-M7 单核；RAM 紧张；不接受动态内存与运行时管理开销；厂家库够用就复用。
方案
调度表在编译期用 X-Macro 展开，顺序与相位静态确定；引擎只持指针与计数，数组由组合根（调用方）拥有；data_bus 退化为无状态纯算法，每个 topic 注入内存。
结果
新增任务只需加一条表项；slot 级 enabled 支持动态启停且不破坏相位；引擎不再越层管理内存。
02

麦轮底盘 — 速度环与里程计

四轮直驱 + 陀螺仪 / 6 电机轮询
本体迭代中

正向运动学矩阵满足 KᵀK = 4I，伪逆可平凡求解。目标是不依赖 IMU 达到世界级精度——IMU 只用来测角速度，不用来测角度。

展开复盘
问题
开环里程计存在横漂，且不是均匀分布：每次起步后大约 80ms 出现一次角速度尖峰，最差量级 6.7mm。
约束
陀螺仪 50Hz、比例因子有约 3% 校准误差，只能当角速度源；优化期内冻结位置模式，只动速度模式；6 台电机同优先级，底盘不得独占轮询。
方案
三轴速度环闭环——vx/vy 取电机正解算速度，yaw 角速度只信陀螺仪；起步 ramp 释放时做外推修正；观测侧先升级，机制后动。
结果
横漂根因锁定到 ramp 释放瞬间而非通信丢帧，修正方向已定；三个量化误差源（指令量化、单轮速度环欠给、驱动栅相位）已分别定位。
03

并联 SCARA — 关节空间控制

双电机共底座 / 1:10 减速 / 镜像安装
本体设计阶段

中间折叠实现前后双工作平面，中间无遮挡。关节空间先行，不插补，不做机械限位，零点手动标定。

展开复盘
问题
双电机共底座、镜像安装，上电没有绝对零位；两个关节还共用同一条总线。
约束
无机械限位可参考；不插补；运动学解算排在关节空间之后；五杆连杆尚未安装。
方案
上电默认零点 + 手动标定方向；指令在同一帧内按多地址同步下发，保证确定性，拒绝广播触发；关节角用单圈线性化编码器位与多圈位置位组合解算。
结果
首版关节空间控制就位，方向标定由代码侧承担；运动学解算是下一步。
